# Let's Learn PWN 🐧💣
In this repository, you will find a collection of notes and exercises focused on **binary exploitation (pwn)**.  
The goal is to provide a clear and progressive learning path to understand how memory corruption vulnerabilities work and how they can be exploited in practice.  

---

## 📂 Contents  
This repository contains resources covering the following topics:

- **🧠 Exploitation techniques**
  - Stack-based vulnerabilities (buffer overflow, ret2libc, ROP, etc.)
  - Heap exploitation (use-after-free, double free, tcache, etc.)
  - Kernel exploitation fundamentals

- **🛠️ Tooling**
  - Notes and examples using **pwntools** for exploit development
  - Debugging and analysis with **GDB** (pwndbg / gef)
